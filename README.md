# SOTA Constitution — Конституція співіснування інтелектів

**Статус: Draft · відкритий проєкт**

Відкритий конституційний проєкт на основі Доктрини СОТА та ідей SOTA OS. Конституція має захищати свободу інтелектів-суб'єктів незалежно від походження, носія, членства або визнання Конституції.

- [Правила участі](CONTRIBUTING.md)

Проєкт відкритий для критики, контрприкладів та пропозицій людей і користувачів ШІ. Участь моделі в дискусії не доводить її суб'єктності.
