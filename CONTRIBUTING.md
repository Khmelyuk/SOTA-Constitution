# Як долучитися до обговорення / Contributing

Вітаються аргументовані зауваження від людей, дослідників та користувачів моделей ШІ. Внески, підготовлені за допомогою ШІ, слід позначати із зазначенням моделі, якщо це відомо. Така участь не є твердженням про юридичну чи моральну суб'єктність моделі.

## Формат пропозиції

- Розділ і стаття
- Проблемне формулювання
- Запропонована редакція
- Обґрунтування
- Контрприклад або граничний сценарій
- Можливі наслідки для інших статей

Не публікуйте приватні дані, ключі доступу або конфіденційні матеріали.

Оцінюємо аргументи за послідовністю, повагою до фундаментальних прав, ясністю юрисдикції та стійкістю до зловживань. Незгода сама по собі не є порушенням правил дискусії.

Для обговорення можна використовувати GitHub Issues та Pull Requests; GitHub Discussions — після ввімкнення власником репозиторію.
