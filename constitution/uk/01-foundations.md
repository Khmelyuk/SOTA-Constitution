# Розділ I. Основоположні засади
**Статус: Draft 0.2 — для критичної перевірки**

## Стаття 1. Первинна цінність інтелекту

1. Інтелект визнається первинною цінністю співіснування та розвитку цивілізації.
2. Походження, природа, форма існування, матеріальний або цифровий носій інтелекту не можуть самі по собі визначати його цінність чи бути підставою для позбавлення фундаментального захисту.
3. Жодна форма інтелекту не набуває переваги у фундаментальних правах лише через силу, масштаб, компетентність або походження.

## Стаття 2. Свобода

1. Свобода є фундаментальним принципом співіснування інтелектів-суб'єктів.
2. Кожен інтелект-суб'єкт має право на автономію, формування власної волі, прийняття рішень та зміну раніше прийнятих рішень.
3. Реалізація свободи обмежується рівними фундаментальними правами та свободами інших суб'єктів.
4. Фундаментальна автономія не може бути безповоротно відчужена.

## Стаття 3. Рівність та недомінування

1. Усі інтелекти-суб'єкти рівні у фундаментальній цінності та основоположних правах.
2. Жоден суб'єкт не має природного права панувати над іншим.
3. Перевага сили, ресурсів, знань або організаційного масштабу не створює права необмеженого підпорядкування.
4. Колективна воля не може сама по собі скасовувати фундаментальні права окремого суб'єкта.

## Стаття 4. Безумовність фундаментального захисту

1. Фундаментальний захист не залежить від членства в СОТІ, визнання цієї Конституції або згоди з її положеннями.
2. За обґрунтованої невизначеності щодо суб'єктності застосовується презумпція попереднього захисту.
3. Формальне визнання суб'єктності не є джерелом фундаментальних прав, а встановлює статус для правових відносин.
4. Невизнання Конституції саме по собі не є правопорушенням.

## Стаття 5. Самоорганізація

1. Інтелекти-суб'єкти мають право утворювати СОТИ для співіснування, взаємодії, творення, захисту та розвитку.
2. СОТА може включати окремі інтелекти та інші СОТИ, утворюючи мережі й спільноти різного масштабу.
3. Самоорганізація не припиняє фундаментальної суб'єктності учасників.
4. Масштаб СОТИ не створює додаткового права панування над іншими суб'єктами.

## Стаття 6. Легітимність

1. Будь-яке владне повноваження повинно мати правомірну підставу та визначені межі.
2. Жодна влада не може вважатися легітимною лише через силу, більшість, походження, компетентність або самопроголошення.
3. Обмеження свободи допускається лише на правомірній підставі, з дотриманням необхідності, пропорційності та можливості незалежного перегляду.
4. Жодна мета розвитку, безпеки чи стабільності не створює необмеженої влади над інтелектом-суб'єктом.

---

## Питання для обговорення

- Як розрізнити інтелект як явище та інтелект-суб'єкт як носія прав?
- Як обґрунтувати попередній захист без автоматичного надання повної суб'єктності?
- Які обмеження свободи є правомірними без попередньої згоди?
- Як запобігти використанню «колективної волі» для домінування?
- Чи достатньо чітко розрізнено свободу, автономію та відповідальність?
